Gemini API Key Tester

Test if your API key works before using damage-detection. Calls Google directly from your browser.

⚠️ For local testing only. Your key stays in this tab (sessionStorage). Never commit keys or share this page publicly with a key filled in. New Google accounts: gemini-2.5-flash returns 404 — use gemini-3.6-flash (current default). Docs: Gemini 3.6 Flash.

Configuration

Quick test (curl):
curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.6-flash:generateContent" -H "x-goog-api-key: YOUR_KEY" -H "Content-Type: application/json" -d "{\"contents\":[{\"parts\":[{\"text\":\"ok\"}]}]}"

Backend (if damage-ai running): GET http://localhost:3000/health/gemini
Set AI_MODEL=gemini-3.6-flash in root .env then docker compose up -d --build.
